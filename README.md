# CodeAlpha_BuildCalculator
Build Calculator

A simple calculator application that performs basic arithmetic operations such as addition, subtraction, multiplication, and division.

Features

Addition

Subtraction

Multiplication

Division

Clear/reset functionality

User-friendly calculator interface

Handles invalid input and division by zero

Tech Stack

HTML

CSS

JavaScript

build-calculator/
├── index.html
├── style.css
├── script.js
└── README.md

Getting Started
1. Clone the repository
git clone <repository-url>

2. Navigate to the project
cd build-calculator

3. Run the application

Open index.html in your browser.

No additional dependencies or installation steps are required.

How It Works

Enter the numbers using the calculator buttons.

Select an arithmetic operation.

Enter the next number.

Press = to calculate the result.

Use C or the clear button to reset the calculator.

Example
10 + 5 = 15
20 - 8 = 12
6 × 7 = 42
20 ÷ 4 = 5

Error Handling

The calculator should handle invalid operations gracefully. For example:

10 ÷ 0


should display an appropriate error message instead of producing an invalid result.
