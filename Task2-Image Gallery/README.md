## 📌 Project Overview

This project is a modern and responsive **Image Gallery Website** developed as part of the **Frontend Development Internship - Task 1**.

The website displays a collection of 12 images organized into different categories. Users can easily filter the images, open an image in a full-screen lightbox, and navigate between images using buttons or keyboard controls.

The project is created using:

* HTML
* CSS
* JavaScript

The main goal of this project is to demonstrate frontend development skills, responsive web design, JavaScript functionality, user interaction, and clean UI design.

---

## ✨ Features

### 1. Responsive Image Gallery

The website contains **12 images** displayed in a clean and attractive gallery layout.

The gallery is responsive and works on:

* Desktop
* Laptop
* Tablet
* Mobile phones

---

### 2. Image Categories

The images are divided into the following categories:

* **All**
* **Nature**
* **Animals**
* **Cities**

Users can click on a category filter to display only the images belonging to that category.

---

### 3. Full-Screen Lightbox

When a user clicks on an image, the selected image opens in a full-screen lightbox.

The lightbox provides a larger view of the image along with its title and category.

---

### 4. Previous and Next Navigation

The lightbox contains:

* Previous button
* Next button
* Close button

Users can move between gallery images without closing the lightbox.

---

### 5. Keyboard Navigation

Keyboard controls are also supported.

| Key         | Action         |
| ----------- | -------------- |
| Left Arrow  | Previous image |
| Right Arrow | Next image     |
| Escape      | Close lightbox |

This makes the gallery easier and faster to use.

---

### 6. Hover Effects

Images include smooth hover effects.

When the user moves the mouse over an image, the image responds with a smooth visual transition.

These effects provide a modern and interactive experience.

---

### 7. Smooth Transitions

CSS transitions and JavaScript interactions are used to create smooth animations between:

* Image hover states
* Category filters
* Lightbox opening
* Lightbox closing
* Image navigation

---

## 🖼️ Gallery Categories
